# 笺读 1.9.99.74 · 终极版真机验收指南

> 版本：`1.9.99.74 / 313`（universal，x86_64 + arm64）
> 定位：V2.0 收官版。主阅读器稳如磐石（竖排古籍），双屏对照模式打通「左图右文 + 滚动联动 + 横排扩展」，可直接拿横排绝版书扫描件试跑。
> 适用对象：你自己（开发者 / 内测）。给真机第一天验收用，大白话，1 分钟上手。

## 0. 先把包装好

- 最新包：`dist/笺读-1.9.99.74.dmg`
- 双击 DMG → 把「笺读.app」拖进「应用程序」文件夹即可。
- 装好后路径：`/Applications/笺读.app/Contents/MacOS/jiandu`

> ⚠️ **对照模式必须用终端启动**（见下文）。双击图标进的是普通阅读器，不会进对照模式——这是故意的，对照模式是开发者预览，零侵入 V1.0 入口。

## 1. 竖排古籍（主阅读器 · 最稳的一条路）

这是 V1.0 主路径，闭眼用：

1. 双击「笺读.app」正常打开 → 进书架。
2. 点一本书 → 进入竖排正文（宋体、朱砂句读、双行夹注、专名线全在）。
3. 想导出：顶栏最右「更多 → 导出」里有「导出 TEI/XML」「导出当前页图片」「导出 MD」等。

> 这条路径与对照模式完全无关，V1.0 纯净，随便造。

## 2. 双屏对照模式（开发者预览 · 测联动）

### 2.1 启动命令（终端里粘）

```bash
# 竖排古籍对照（右栏默认竖排）
JIANDU_DEV_COMPARE=1 /Applications/笺读.app/Contents/MacOS/jiandu

# 横排现代书对照（明天测绝版书就用这一条）
JIANDU_DEV_COMPARE=1 JIANDU_COMPARE_HORIZONTAL=1 /Applications/笺读.app/Contents/MacOS/jiandu
```

可选：启动时就带上原图和坐标（也可进界面后用按钮导）：

```bash
JIANDU_DEV_COMPARE=1 JIANDU_COMPARE_HORIZONTAL=1 \
  JIANDU_COMPARE_IMG=/Users/你/扫描件.jpg \
  JIANDU_COMPARE_JSON=/Users/你/坐标.json \
  /Applications/笺读.app/Contents/MacOS/jiandu
```

> 关键：`open 笺读.app` 会**丢掉环境变量**，必须直接跑 `MacOS/jiandu` 二进制才能进对照模式。

### 2.2 界面长什么样

顶部一条操作栏（仅对照模式有，普通阅读界面看不到，保证 V1.0 纯净）：

- 蓝色按钮「导入原图」→ 弹系统文件框，选一张 JPG / PNG 扫描件，进左栏。
- 红色按钮「保存对照图」→ 把当前双屏对照存成高清 PNG（离屏重绘，Retina ×2 防马赛克）。
- 左栏标题「左 · 扫描影印原图」，右栏标题「右 · 横排正文」（横排）或「右 · 现存竖排正文」（竖排）。

### 2.3 右栏文字从哪来（重点）

右栏正文有三种来源，按优先级：

1. **坐标 JSON 的 `text` 字段**（最干净，推荐试横排绝版书时用）。
   - 自己手打的横排文字，写进一个 JSON 文件的 `text` 里，段落用 `\n` 分隔，每满 30 字自动折行。
   - 模板见文末附录。
2. **已打开的书**：若启动带了 `JIANDU_AUTO_READ=1` 且书库非空，右栏回退用该书正文（此时无命中联动）。
3. **手动输入的编辑器**：本版**尚未做**实时文本框（V2.1 排期）。所以「手打横排文字」现阶段请用第 1 种——把文字写进 JSON 的 `text` 字段，这是已验证可用的入口。

### 2.4 联动怎么验（明天验收核心）

- **正向**：鼠标点左图某个字 → 右栏对应字亮**红框**。
- **反向**：鼠标点右栏某字 → 左图对应字亮**红框**。
- **滚动同步**：滚轮滚左图，右文按同比例平滑跟随；滚右文同理。比例是 `offset / max_offset`，与排版方向无关，所以横排竖排都一样顺。

> 验证联动不需要坐标 JSON：`glyphs` 留空 `[]` 也能滚；只是没有「点字红框」的精确命中，滚动同步照样跑。

## 3. 拼音 / 注音（预留状态 · 如实说明）

- **主阅读器**：「生僻字注音」默认开启（prefs.rare），生僻字右上角带拼音小字——这是 V1.0 现成功能。
- **对照模式内叠注音**：本版为**预留状态**，尚未在右栏激活。也就是说，对照模式下右文目前**不带**拼音注音。这是已知「留待后续」项，不是 bug。

---

## 4. 导出标准 TEI / XML（数字人文 P5 格式）

- **入口**：主阅读器顶栏「更多 → 导出 → 导出 TEI/XML」。
- **底层**：`jiandu_core::exporter::export_tei` 已用真实《資治通鑑》跑通。
- **格式保证**：
  - 正文 / 夹注 / 批注**三路严格分离**（`<p>` / `<note type="gloss">` / `<note type="annotation">`）。
  - 实体用标准 TEI P5：`<persName>` 人名、`<placeName>` 地名、`<title level="m">` 书名。
  - 注音 `<ruby>`、着重 `<hi>`、眉批 `place="top"`，全按标注类型强制分流。
- **激活闸提示**：导出 / 印制受内测闸控制（首跑 7 天窗口，或填测试码视同已激活）。你是开发者，内测期内直接用；若提示「需先解锁」，用测试码或等窗口内即可。阅读、批注、对照**永远不受闸**。

## 5. 明天测横排绝版书 · 最简流程

1. 拿到绝版书扫描件（比如一页 JPG）。
2. 写一个小 JSON（见附录模板），把这一页你手打的简体横排文字放进 `text`。
3. 终端起：
   ```bash
   JIANDU_DEV_COMPARE=1 JIANDU_COMPARE_HORIZONTAL=1 \
     JIANDU_COMPARE_IMG=/路径/扫描件.jpg \
     JIANDU_COMPARE_JSON=/路径/文字.json \
     /Applications/笺读.app/Contents/MacOS/jiandu
   ```
4. 看左图、右文是否对齐流式横排；滚轮验联动；点「保存对照图」存一张高清图。
5. 有不对的地方记下来，后天排 V2.1。

## 附录 A · 环境变量速查

| 变量 | 作用 | 默认值 |
|------|------|--------|
| `JIANDU_DEV_COMPARE` | 存在即进双屏对照模式 | 关（普通阅读器） |
| `JIANDU_COMPARE_HORIZONTAL` | 存在即右栏横排（现代书），否则竖排 | 竖排 |
| `JIANDU_COMPARE_IMG` | 左图预载路径 | 进界面用「导入原图」 |
| `JIANDU_COMPARE_JSON` | 右文 + 坐标 JSON 路径 | 进界面用「导入原图」+ 书 |
| `JIANDU_COMPARE_HIT=<n>` | 预置命中第 n 个字（演示） | 无 |
| `JIANDU_COMPARE_SCROLL_TEST` | 启动后自动滚左图到 ~45%（演示） | 无 |
| `JIANDU_AUTO_READ` | 启动自动开第一本书（右栏回退用书正文） | 关 |

## 附录 B · 对照模式右文 JSON 模板

```json
{
  "image_width": 1200,
  "image_height": 1800,
  "text": "第一章 归来\n这是一段横排简体的测试文字，用来校对绝版书扫描件。\n第二段可以另起一行，每满 30 字自动折行。",
  "glyphs": []
}
```

- `image_width` / `image_height`：扫描件原始像素尺寸（用于把命中框换算回图像坐标）。
- `text`：右栏正文，**段落用 `\n` 分隔**；横排模式下每 30 字折一行。
- `glyphs`：留空 `[]` 也能滚；要「点字红框」精确联动，需填每个字的 `{x,y,w,h,target}`（target = 右文全局字符下标，从 0 起）。OCR 接入后会自动生成这一块（见 V2.1 排期）。
