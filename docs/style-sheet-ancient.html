重构要点

  • 字级：四颗方块按钮与 42pt 一律去掉，改古称「蝇头 / 中楷 / 大字 / 榜书」。选中只把字染朱砂 #B23A30，字下压一道 1px 墨线；档位字 13px，比行内其他选项略大一档，便于一眼定位。
  • 字体：刻本 / 手写两张卡片去掉粗边与深底，未选完全透明；选中时淡朱底 rgba(178,58,48,.07) + 1px dashed 朱砂虚线（outline-offset:-1px，不占布局），字与副题同转朱砂。
  • 底部：灰底大方框改为纯文字按钮，宋体 11.5px，前置 12px 线框 icon（stroke: currentColor），悬停字色加深、按下转朱砂。
  • 关闭：右上角灰底按钮改为「收起」二字，无底无框，悬停转朱砂。
  • 面板：rgba(240,234,214,.95) 宣纸底 + backdrop-filter: blur(10px)，1px 极淡界线，2px 圆角，投影只向下（0 18px 42px -20px），像一张薄纸浮在书页上。

与客户端实现的对应

  • GPUI 0.2.2 不支持 backdrop-filter：客户端以「纸色 + 95% 不透明」的 rgba 近似透纸感，其余（细线、朱砂、无底、宋体、向下投影）逐条落地，见 src/reader.rs 的 panel_tab / ink_option / text_action / font_preset_row。
  • GPUI 无 dashed 边框，虚线用「2 实 2 虚」的 1px 短横排出（zhu_dashed）；HTML 版直接用 dashed，两者视觉一致。
核心 CSS（可复制） 
.panel {
  background-color: rgba(240, 234, 214, .95);
  -webkit-backdrop-filter: blur(10px) saturate(1.05);
  backdrop-filter: blur(10px) saturate(1.05);
  border: 1px solid rgba(120, 100, 70, .18);
  border-radius: 2px;
  box-shadow: 0 18px 42px -20px rgba(52, 40, 26, .55),
              0 2px 6px -3px rgba(52, 40, 26, .18);
  font-family: "WenJinMincho", "Songti SC", "Noto Serif SC", serif;
  color: #2B2622;
}

/* 选中态只做两件事：朱砂字 + 1px 墨线 */
.opt, .size, .tab { color: #2B2622; background: none; border: 0; padding: 0; }
.opt::after, .size::after, .tab::after {
  content: ""; display: block; width: 0; height: 1px;
  background: #2B2622; transition: width .22s ease;
}
.opt[aria-pressed="true"], .size[aria-pressed="true"], .tab[aria-selected="true"] {
  color: #B23A30;
}
.opt[aria-pressed="true"]::after,
.size[aria-pressed="true"]::after,
.tab[aria-selected="true"]::after { width: 22px; }

/* 字体卡：透明底 → 淡朱底 + 朱砂虚线 */
.preset { background: transparent; border: 0; outline: 1px dashed transparent; outline-offset: -1px; }
.preset[aria-pressed="true"] {
  background: rgba(178, 58, 48, .07);
  outline-color: rgba(178, 58, 48, .55);
  color: #B23A30;
}
