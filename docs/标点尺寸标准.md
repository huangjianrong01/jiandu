# 标点尺寸标准（句读形制）

> 适用范围：笺读竖排阅读器与 PDF 导出共用的句读（标点）排版口径。
> 屏幕与 PDF 永远画同一枚形——分类归内核符号库 `jiandu_core::gloss::Jodu`
> 管，手绘只接在 `crates/app/src/punct.rs`，两者查同一张表。

## 0. 设计总则

刻本的句读**绝不是「缩小的正字」**，更不是现代印刷体的 `，。` 字形：字库自带的
标点在极小字号下会缩成一枚「奇怪的黑痣」。故本模块**严禁调用字体的句读字形**——
所有标点一律在渲染前拦截，用 `paint_path` 纯手绘（见 `punct.rs::paint_mark`）。

句读是附在字隙里的小朱记，**不是缩小的正字**；墨主朱辅，轻重有度。

## 1. 尺寸口径（唯一数据源：`Jodu::fs_ratio`）

记号直径 = 正文字号 × 下表比例。渲染与 PDF 共用，由 `PunctKind::fs_ratio()`
委托 `jiandu_core::gloss::Jodu::fs_ratio()`，**屏幕与 PDF 同一张表，绝不允许分叉**。

| 符号库形制 | 语义 | 直径 / 正文字号 | 备注 |
|---|---|---|---|
| `Jodu::Seed` | 读（，、；：—…） | **0.42** | 圆头斜点，撑住行气，故最重 |
| `Jodu::Ring` | 句（。．，古籍模式） | **0.38** | 古风小圆圈「〇」，只作收束，故最小 |
| `Jodu::BigSeed` | 疑叹（？！，古籍模式） | **0.45** | 「读」的加强，最大 |
| `Jodu::Dot` | 现代句（。，现代模式） | **0.38** | 细线空心圆 |

> 三者都落在 **38%–45%** 区间内，绝不探出半字格。这是 v1.9.89 的整体收敛：
> 此前读（0.54）/ 疑叹（0.62）偏大，真机观感喧宾夺主（小红书用户反馈
> 「圆圈句号 ○ 和顿号 、 太抢眼」）。现压回这一档，回归「墨主朱辅」。
>
> 刻本规矩：**句比读小**——句末那一圈只作收束，读处那一点要撑住行气故更重，
> 疑叹最重。与「现代标点句大而读小」的直觉相反，是有意为之。

## 2. 硬上限（防溢出第一道闸）

`punct.rs::place()` 对圆圈类额外加一道硬上限：外径（横径 = `d × (1 + RING_OVAL)`）
**绝不**超过主字格 Em 的 **50%**：

```rust
let cap = match kind {
    PunctKind::Ring => (fs_body * 0.5 / (1.0 + RING_OVAL)).min(room),
    PunctKind::Dot  => (fs_body * 0.5).min(room),
    _ => room,
};
let d = (fs_body * kind.fs_ratio()).max(kind.min_d()).min(cap);
```

`room = (cell_w * 0.5).min(cell_h * 0.5)`：即便正文字号涨到离谱、或格子窄到离谱，
记号也不会探出字格、压到邻列（竖排右邻是上一列，压过去就是串行）。

## 3. 落位与绝对居中

* **落点**：记号中心落在字格 **右上象限**——`ANCHOR_X = 0.72`、`ANCHOR_Y = 0.28`。
  竖排里上一字在上方，句读贴在它的下沿、偏右悬着，不挡字、不占位。
* **圈类绝对居中**：空心圈 / 〇 的形状本就绕中心 `(cx, cy)` 对称绘制
  （`paint_classic_ring` / `paint_dot`），「居中」不靠偏移补；只调中心坐标，
  绝不改形状自身的对称。
* **瓜子点悬空**：读类（斜点）落位后再向左、向下各让 `SEED_NUDGE_PX = 1.0` px
  （`CUBIC_NUDGE_PX = 0.5`），不贴死前一字、不贴右缘；圈类居中即正、不悬。
* **悬挂句读**：被挤压进末字格的那枚句读走 `place_hang()`，X 推到字格右缘
  （`HANG_ANCHOR_X = 0.86`）、纵向沉到末字脚下（`HANG_ANCHOR_Y = 0.80`），
  与末字错开、绝不顶到下一列首格。

## 4. 矢量重算（边缘锐度）

所有句读形状**全部手绘矢量**，绝不在缩放时取字体字形：

* 读点（斜点）：`SEED_H_RATIO = 0.54`（长 / 正文）、`SEED_W_OF_H = 0.37`（宽 / 长）、
  `SEED_BELLY_AT = 0.47`（最宽处落在全长 0.75，毛笔古意）、`SEED_TILT_DEG = 42.0`
  （笔势倾角，顺时针，与精刻本照片 PCA 实测 41.4° 同源）。
* 古风「〇」：`RING_STROKE_OF_D = 0.30`（笔画厚 / 直径），比现代细圈（0.22）厚一档，
  是「写」出来的圈不是勾出来的几何圆；略带椭圆。
* 现代空心圈：`STROKE_OF_D = 0.22`（细而不虚，内孔仍留得出来）。

缩小 / 放大都是几何重算，不是位图缩放——任意字号下边缘都锐利。

## 5. 防溢出 Clamp（动态防碰撞）

`punct.rs::collision_fit()` 是防溢出的**唯一源**：

1. 若真实墨迹（含洇边 `CUBIC_BLEED_SCALE`、TTS 脉冲 `PULSE_PEAK`、悬针 1.30 倍）
   比字格（扣 `PUNCT_SAFE_PAD = 0.5` px 安全留白）还大 → 返回 `k < 1`，整枚记号
   **等比缩下来**（折进 `PunctMark.d`），屏幕与 PDF 同读这个 `k`；
2. 中心按「左 / 右、上 / 下各自的距离」**分别 clamp** 回安全区——
   出锋拖左上就只回拉左 / 上，不会把圆头那侧也一起拽偏（记号整体不对称，
   对称的单半径 clamp 必漏）。

不变量：`cx − e.left ≥ pad`、`cx + e.right ≤ cell_w − pad`，纵向同理。

## 6. 呼吸感

* 瓜子点悬空微调（§3）让记号浮在字外，又不会看着像跑偏；
* 密排时 `anchor_x_for(cell_w)` 在 `DENSE_CELL_W=40 → SPARSE_CELL_W=52`
  连续插值 `0.72 → 0.80`，杜绝切字号跳位；
* 42° 倾角下记号只占约 0.37 字格宽，是一枚斜置的墨点而非一横，留白自然。

## 7. 颜色

句读墨色 = **暗朱砂 / 熟褐**，与夹注同源（渲染层传 `palette.zhu()` / `palette.note()`）。
形状与位置是新制的，颜色照旧不动（用户点名「还是原来的颜色」）。

## 8. 红线（改动防护）

* 句读尺寸**只允许改 `Jodu::fs_ratio` 与 `punct.rs` 顶部常量**两处，且屏幕 / PDF
  必须同改同测；
* 圈外径 50% 硬上限（`place()` 的 `cap`）**不可拆**；
* `collision_fit` 的「真实墨迹四向 clamp + k<1 缩形」不可退回旧的对称单半径 clamp；
* 任何标点都只能去**适应格子**，绝对不允许反过来修改字体的基准缩放
  （主字 `reader.rs` 的 `.text_size(px(fs))` 与标点几何互不相干）。
