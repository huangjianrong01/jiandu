### 1.2 「系统商用受限字体」到底要不要换？——不要，理由如下

Apple 系统字体的许可约束的是**字体文件的复制与再发行**，不是「在 macOS 上使用它」：

* 我们**没有**把 `Songti SC` 等字体的文件拷进 `.app`（包内 `Resources/fonts/` 是空的，
  唯一字库是 OFL 的齐伋体）；
* 我们只是向系统请求「用 Songti SC 排这段字」，字形来自用户自己那台 Mac 的系统字库；
* PDF 导出用 `CGPDFContext` 落笔，字体子集由系统自行内嵌——这与 TextEdit、Pages
  导出 PDF 是同一机制，属于**文档内嵌**，不是字库发行。

所以「换成 Source Han Serif / LXGW WenKai」**不会降低任何法律风险**，反而会让
开箱即用的观感从「系统宋体」变成「没装的字 → 静默回退」，也就是把风险换成体验损失。

真正该做的两件事，都已完成：

1. **齐伋体补 OFL 文本**（原本是违约状态）；
2. **在回退链里插一枚随包的 OFL 字**，让「没装商业字库」的用户落在一个我们
   自己说了算的字上，而不是系统默认宋体。

### 1.3 唯一需要你点头的一条：出厂默认指着商业字库

`prefs.rs::default_font_ancient()` 的出厂正文是 **方正清刻本悦宋**
（v1.84.0 你亲自定稿的那一款）。它不随包，法律上没问题；产品上有一处遗憾：
**没装这款字的新用户，出厂观感落在一个他没选过的字体上。**

本次已做的改动（不影响你本机）：

```
FontChoice::FZQingKeBen 回退链：
  方正清刻本悦宋 → 方正…-GB → 【新增】QIJI 齐伋体 → Songti SC → serif
```

* 你装了方正 → **一切照旧**，一个像素都不变；
* 没装 → 退到**随包的齐伋体**（明刻本活字，OFL），而不是系统宋体。

若你希望更彻底（出厂就是齐伋体，不依赖任何商业字库），改 `prefs.rs` 里那
一行 `FZQingKeBen` → `Qiji` 即可，一行的事。**这一条等你决定，我没有擅改。**

## 3. 依赖（Rust crate）

命令：`python3 scripts/license_audit.py`（新增，离线可复现）

```
Cargo.lock 内第三方包：747 个
构建图内（cargo tree -e normal,build）：499 个
协议分布：MIT OR Apache-2.0 310 / MIT 170 / Apache-2.0 OR MIT 70 / Apache-2.0 22
          Unicode-3.0 18 / BSD-3 12 / Zlib 9 / Unlicense 7 / BSD-2 4 …
① 只能选 copyleft：无
② 多选一、含 copyleft 备选：3 处（按宽松那条用即可）
     r-efi 5.3.0 / 6.0.0   MIT OR Apache-2.0 OR LGPL-2.1-or-later  → 取 MIT
     self_cell 1.3.0       Apache-2.0 OR GPL-2.0-only              → 取 Apache-2.0
③ 本地缓存缺失 25 个：cosmic-text / freetype-sys / linux-raw-sys / winapi /
     windows 系列——全部是**其他平台**的依赖，macOS 构建不参与（cargo tree 可证）
```

**结论：0 个 GPL / AGPL / SSPL 传染依赖。**

关于 §3 的两点说明：

* 「出现 GPL 字样」不等于传染。Rust 生态大量包是 `MIT OR Apache-2.0 OR LGPL-2.1`
  这种**多选一**，只要有一条宽松选项，我们按那条使用即可。脚本把「含 GPL」
  与「**只能**选 GPL」分开统计，正是为了避免这种误判。
* Apple 系统框架（**StoreKit / PDFKit / CoreGraphics / CoreText / AppKit /
  Foundation**）不是开源依赖，是平台 API，按 macOS SDK 许可使用，与 GPL 无关。
  本次接内购新增的 `StoreKit` 框架链接同此。
