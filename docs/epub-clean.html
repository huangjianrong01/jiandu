横排电子书的产物直接进竖排引擎，有三处会崩：数字被拆成单字（14428 → 1/4/4/2/8 竖着摞）、 现代标点突兀（《》立在列里、（）占了两个字格）、内嵌小字破坏行气（<sup> 一行插进两个小字）。 下面这条管线把 xhtml 一路洗成竖排能读的 { title, content }，只留三种标记： [注] 双行夹注、[高亮] 朱砂圈点、[拼音:] 格内注音。

入原始 xhtml可自行粘贴

出最终结构[{ title, content }]

—

①结构降噪剔噪块 / 广告 / 颜色

—

②标记提取ruby → 拼音；noteref → 夹注

—

③标点古籍化《》→︽︾；（）→[注]

—

④数字清洗转汉字 / [数字:] 兜底

—
为什么顺序不能换：注文必须先抽（脚注体常装在 <aside> 里，降噪会连它一起删）； ruby 必须先于数字（<rt> 里的音调数字会被数字清洗误伤）； 页码孤行必须先于数字转汉字（先读成「十二」就再也认不出它原本是个页码）。
