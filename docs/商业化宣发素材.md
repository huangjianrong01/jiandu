# 笺读 · 商业化宣发素材

> 用途：三核心卖点 + 三句海报级文案。可直接拿去发小红书 / 知乎。
> 产品定位：笺读（JianDu）—— 把绝版古籍与现代绝版书，还原成「可对照、可校对、可输出」的数字工作台。

---

## 一、三个核心卖点（一句话版本）

### 卖点 1 · 古籍绝美排版（0.008px 朱砂句读）
不是「能显示古文」，而是**还原线装书的灵魂**：宋体竖排、双行夹注、专名线 / 书名线、天头地脚 3:2 古法行款，连句读朱点都精确到 0.008px。打开一本书，像翻开一册真古籍，而不是一堆乱码竖线。

### 卖点 2 · 双屏图文智能联动（左图右文，平滑滚动）
独创「双屏对照模式」：左边是扫描影印原图，右边是校对后的文字，**点左图一个字，右文对应字立刻亮红框；滚动左图，右文按比例丝滑跟随**。校对绝版书、影印本再也不用左右来回挪眼睛、手动对行。

### 卖点 3 · 生产力级数据输出（一键导出 TEI / XML 知识图谱标准格式）
不只是「看」，更是「用」：一键导出 **TEI P5 国际标准格式**，正文 / 夹注 / 批注三路分离，人名、地名、书名自动标成标准实体标签。直接喂给数字人文知识图谱、语料库、学术检索——古籍瞬间变成结构化数据资产。

---

## 二、三句海报级文案

### 文案 A · 小红书（种草 · 视觉向）
> **「把绝版线装书，装进 Mac。」**
> 宋体竖排、朱砂句读精确到 0.008px，翻开笺读就像翻开一册真古籍。左图右文双屏对照，点字即亮、滚动同步——校对绝版影印本，眼睛终于不用左右横跳了。📜✨

### 文案 B · 知乎（专业 · 价值向）
> **「古籍数字化的最后一公里，是『可输出』。」**
> 市面上的古籍 App 止步于「能看」。笺读做到「能校对、能对照、能导出」：双屏图文智能联动，一键生成 TEI P5 标准 XML，正文 / 夹注 / 批注三路分离，人名地名书名自动标注。把一部绝版书，变成可直接进知识图谱的结构化资产。这才是数字人文该有的生产力。

### 文案 C · 双平台通用（一句话钩子）
> **「左图右文，点字即亮；看完古籍，导出标准。」**
> 笺读 = 绝美古籍排版 + 双屏智能对照 + TEI/XML 一键输出。绝版书不再只是压箱底的纸，而是能检索、能引用、能传承的数据。
