三种模式的核心差异

  • 对开翻阅（Spread）：单叶可用宽 = (内容宽 − 中缝) / 2，两叶 + 中缝铺满屏幕，中缝落在正中并立鱼尾 / 叶码；视线自右向左扫视。
  • 手机竖屏（Mobile Portrait）：整幅宽都给这一叶，中缝不画、纸面贴屏幕右缘；列宽约为对开时的两倍——同一个字号，手机上反而更大。
  • 整页（Full Page）：按 fullScale = min(w/1180, h/820) 取系数，只对外层做 ctx.scale(k, k)，内部按基准版式原样绘制；列数、行数、字格比例全部不变，变的只是整体大小。

网格算式（三模式共用）

  • colWidth = 可用宽 / columns，字号随列宽线性缩放：fontSize = 0.75 × colWidth，rowHeight = 1.1 × colWidth × lineScale，totalRows = floor(可用高 / rowHeight)。
  • 最小字号阈值 12px：跌破时反推列宽（宁可纸面略宽、由外层滚动），14 列窄屏也不会小如蚂蚁。
  • 切列数 / 切模式都先记 charIndex 锚点（当前页首字的章·段·偏移），重排后按它回找新页码——绝不跳回卷首。
  • ResizeObserver + window.resize（120ms 防抖）→ 重新 calculateGrid；自动模式只在对开 ⇄ 单叶之间来回，整页是手动档。
