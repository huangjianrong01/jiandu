# 清洗规范（文本卫生与夹注/异体处理）

> 适用范围：书籍导入（`core::importer`）+ 笺校工作台文本导入（`app::importer`）
> 共用的清洗口径。原则：**写回书库的清洗与仅作统计/预览的清洗，用的是同一台引擎，
> 但用法分家**——引擎只负责「识别并归一」，绝不擅自改意；要不要落库、要不要统计，
> 由调用方决定。

## 0. 总纲

* 清洗只动「**字一个都没错、但根本不是书**」的脏：零宽字符、简繁混排残留、
  未剥净的格式脚手架、上标注号等。
* **宁漏不误**：判据一律往「只有这一种解释」上收，判不准的一律不动。
* 主字号**一寸不动**：清洗链绝不修改字体缩放；句读 / 夹注的几何只去适应格子，
  反过来改 `fs` 是红线（见《标点尺寸标准》§8）。

## 1. 字数统计口径（唯一源：`core::cleaner::body_char_count`）

* 屏幕显示与 PDF 导出**共用同一函数**，绝不允许分叉；清洗链内部**禁止**
  `chars().count()` 直接计数（夹注升格每处 +7 的差异必须统一走本函数）。
* 口径：逐字符跳过空白与不可见字符（`is_invisible_char`），并**跳过夹注壳标记**
  `[注]` / `[/注]` 自身——**夹注正文照常计入字数**，只有两枚壳不数。
* 一简对多繁、异体归一**不影响字数**（归一到同一字仍算一字）。

## 2. 夹注壳保护（标签闸门）

位于 `core::cleaner`，分「识别」与「剥壳」两步：

* `note_tag_mask(s)` —— 只把**自家壳**字符标 true，其余一律 false。自家具：
  `[注]` `[/注]` `[高亮]` `[/高亮]` `[note]` `[/note]` 及 `[拼音:…]` `[数字:…]`。
  判定走归一化口径（去空白、全角斜杠折半角）。**不是自家壳的（`[1]` 年份注、
  正文里的方括号）一个字符都不许挡**。
* `strip_note_tags(s)` —— 按 mask 删壳、留壳内字：`[注]周纪三[/注]` → `周纪三`。
  断言 `strip_note_tags_never_touches_foreign_brackets`：**外来 `[1]` 原样不动**。
* 外来纯数字标号由 `drop_reference_marks(s)` **整枚删除**（`[1]` `[２]` `［12］` → 空），
  但 `[一]` 等中文数字标号一律不碰（可能是正文真字）。

## 3. 三家注（自动升格双行夹注）

`mark_three_jia_notes(s)` —— 把刻本注家小字自动认成夹注：

* **只认 5 个注家名**：`集解` `索隐` `索隱` `正义` `正義`（正体 / 繁体都认）；
  `題解` `注釋` `按` 等章节体例**一字不动**（把它们也转小字会吃掉正文）。
* 括号四套都认：`【集解】` `〔集解〕` `[集解]` `［集解］`。
* 续行并入、**不留 `\n`**（古籍硬折行不是语义边界，留着会让注文在小字里断开）。
* 收口紧贴上一行注文末尾，绝不占下一行行首（否则夹注会把空行也吞成小字）。
* 热路径防护：全文里连注家名都没有就直接返回原串（`THREE_JIA_LABELS.iter().any(contains)`），
  **绝不用 `contains('[')`** 做热路径判据。

## 4. 外部格式残留清洗（`core::residue`）

专管「原格式的脚手架没剥干净混进正文流」——与 §2/§3 的「文本卫生」是两类脏：

* 汉字间空格：`道 可 道 ， 非 常 道 。`（PDF / OCR / 扒站头号产物）。
* 页码行：`- 12 -` `· 13 ·` `第 14 页` `Page 15 of 300`（整行剥完只剩数字才剥）。
* HTML 实体：`&nbsp;&ldquo;玄之又玄&rdquo;`（且 `;` 会被全角化成 `；`）。
* 点线目录：`第一章　導論………………1`（须 ≥3 个点线**且**行尾是数字）。
* Markdown：`**此句為全書綱領**` `> 案：此句疑衍。`
* 上标注号：`天下皆知美之為美[1]`。
* 破折号：`絕學無憂――此之謂也。`（U+2015 ×2，看着对、量宽不对）。

三条设计铁律：**宁漏不误**、**零开销早退**（全部 `Option<String>`，不命中连 clone
都不付）、**单遍扫描**（`sweep_lines` 把四条行级规则收进同一次 `split('\n')`）。
故意**不做**的：相邻重复行（分不清 OCR 双栏与重章叠句）、`①` `②` 圈号（方书里是
内容不是标号）、重复页眉（需全书频次，小样本必误杀）。

## 5. 笺校工作台文本导入（`app::importer::apply_text_file`）

* **一字不洗**：`read_text_file()` 只做 BOM / CRLF 归一 + `TEXT_MAX_CHARS = 5_000_000`
  截断；`TEXT_IMPORT_HARD_BYTES = 64MiB` 用 `File::open + take(hard+1)` 读取，**绝不信**
  `len()`（稀疏文件 / 伪长度会坑人）。
* 清洗**只在审计卡** `compute_sanitize_card()` 里**只读统计**（同引擎
  `app::importer::cleaner::clean`，但用法与书籍导入不同——不落库）。
* `is_text_path` 与 `is_image_path` **严格互斥**，选择器与拖拽共用 `apply_text_file`。
* JSON 走 `parse_json_collation()` → `jsonkit::flatten_text`（与书籍导入同一口径，
  注疏包 `[注]…[/注]`）；编辑器**原样保留标签**（所见即所改、数据不丢）；
  `strip_note_shells()` 只在竖排预览出图前换成全角括注 `（…）`；`strip_gloss()` 也认
  自家标签，`⌘N` 掩注可整段隐去。两条预览路径（`render_preview_pages` /
  `render_pdf_blocking`）顺序恒为**先剥壳 → 再掩注 → 再 clean_md**。

## 6. 异体字三表（`core::variants`）

**三张表绝不混用**：

* `to_trad` / `to_simp` —— 只给**检索比对**用，**不写回正文**。
* `safe_fold` —— 只收「繁简同形」约 550 条 + 27 对手校，**唯一可写回正文**的表。
* 一简对多繁（如 `发→發/髮`、`钟→鍾/鐘`）**整条禁用**：撞上即进 `ambiguous`
  并三表全删，绝不自动猜。
* `rescue_missing(s, glyphs, table)` 只折异体（可写回）；`rescue_missing_display(s,…)`
  **只喂渲染器**——绝不落库 / 导出 / 计字数。

## 7. PDF 书籍导入（`core::importer::import_pdf_*`）

* `extract_pdf_pages` 逐页抽取，`PDF_BOOK_MAX_PAGES = 1200` / `PDF_BOOK_MAX_CHARS = 80_000`
  到顶即停。
* `strip_running_lines` 只删出现 ≥ 1/3 页数的重复短行（页眉 / 页脚）。
* `pdf_regions` **只留第 1 页**作版面参考；`cluster` 按 x 分桶竖排列（x 降序右→左，
  桶内 y 降序），容差 0.35 字宽。

## 8. 红线（改动防护）

* 字数统计**只准**走 `body_char_count`，屏显与导出同函数。
* `note_tag_mask` 不挡外来 `[1]` 由断言钉死；`[一]` 等中文标号不碰。
* 三家注热路径**绝不用 `contains('[')`**；`題解` 等体例一字不动。
* 异体字三表分家：`to_trad/to_simp` 不写回，`safe_fold` 才写回，一简对多繁整条禁用。
* 清洗链**绝不碰字体缩放**（主字号一寸不动）。
