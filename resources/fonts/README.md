# 随包字体（可选）

把下列字体文件放进本目录即可被程序自动注册（见 `src/fonts.rs`）：

- `SourceHanSerifSC-Regular.otf` —— 思源宋体（古文竖笺）
- `SourceHanSansSC-Regular.otf` —— 思源黑体（现代横笺）

未提供时，程序会沿回退链使用系统已安装的等价字体（宋体 / 系统黑体）。

字体可从 Adobe 官方仓库获取（SIL Open Font License）：
https://github.com/adobe-fonts/source-han-serif
https://github.com/adobe-fonts/source-han-sans
